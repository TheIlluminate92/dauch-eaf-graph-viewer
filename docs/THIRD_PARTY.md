# Third-party components

The application uses Python, NumPy, Plotly/Plotly.js, PyInstaller, and Windows .NET Framework/WinForms. Exact Python package versions are pinned in `requirements-graph.txt`; the build environment is documented in DEVELOPMENT.

These dependencies retain their own licenses and notices. The bundled runtime includes the license files collected by the packaging tools. Maintainers should preserve those files when repackaging and review the dependencies' distributions before broader redistribution. The system .NET Framework and browser are prerequisites rather than installers supplied by this project.
