DAUCH EAF GRAPH VIEWER

Extract the entire ZIP before opening Dauch EAF Graph Viewer.exe.
Keep the engine folder beside the EXE. Python does not need to be installed.
Keep the launcher window open while using the viewer in your normal browser.

1. Drop one or several RPH files on the launcher or the graph page, or click Add RPH files.
2. Choose one of the five standard views:
   Power & heat progress / Phase current balance / Arc stability factors /
   Impedance response / Electrode response.
3. Use One file at a time and Previous / Next, or Overlay files.
   Overlay starts at each file's first sample. Recorded time (UTC) is also available.
   File checkboxes include/exclude recordings in overlay mode.
4. Search all signals to customize the view. Select left/right axes and colors.
5. Name the view and Save. Export/Import view lets Sergio share settings with another PC.
   Thickness controls all plotted lines, from 0.5 to 3 pixels (default: 1 pixel).
   Thickness is remembered in saved/exported views and applies in both comparison modes.

Saved views are stored under your Windows user profile:
%LOCALAPPDATA%\Dauch\EAF Graph Viewer\views.json
The original RPH files are never modified. Everything runs on this computer.
Closing the launcher stops the viewer; saved views remain. Reload recordings next time.
Graph toolbar: zoom, pan, reset, and save a PNG. Click legend entries to hide traces.
Move the mouse over the chart for crosshairs, left/right axis coordinate labels,
and a highlighted time along the bottom. Tooltips still show actual recorded samples.
Turn the mouse wheel over the chart to zoom; double-click to reset the view.
Click once to pin the crosshair, then move the mouse away to read its coordinates.
Keep up to 10 points. Each numbered row shows time and both axis coordinates.
Click a row to select its crosshair, use its X to remove it, or Clear pins to start over.
Live cursor resumes mouse tracking without removing the saved points on this chart.
Pins retain their original coordinates through zoom, line thickness and plot-style changes.
Changing recordings, selected signals, axis assignments or the time axis clears them.
Pins are temporary to this chart session; they are not saved in reusable views.
The PNG toolbar export includes the plotted data, but not the crosshair/pin overlays.
Crosshair coordinates describe the cursor position, not a nearest sample on each signal.
The viewer fits the browser window. Scroll inside the sidebar to reach longer lists.
Plot style offers Lines, Scatter, and Lines + points, and is saved with each view.
Scatter shows recorded samples as dots; in overlays, files use different marker shapes.

WHAT THIS DOES
Displays recorded signals so you can inspect how SmartArc-related power, currents,
stability factors, impedance and electrode response change over a heat and compare heats.
These are inspection views, not automatic fault diagnoses or controller tuning advice.
Raw values are preserved. Site tag documentation is needed to confirm units, scaling,
factor definitions and alarm thresholds. Counters are raw counters, not event detections.
Gaps longer than five seconds are shown as breaks, not connected lines.

FORMAT / VALIDATION
Direct binary RPH reading supports the layout observed in Hoeganaes23217.rph:
644 signals, 3701 samples. Unknown/truncated layouts are rejected explicitly.
The viewer has been checked with five real recordings, Hoeganaes23215 through 23219,
including overlays, scatter, crosshairs and zoom. Synthetic comparison variants are
also used for repeatable automated package checks. Other RPH layouts remain unverified.
The earlier six CSV files are not RPH validation samples.
Duplicate file contents are loaded once, even if renamed. Per-file limit: 128 MB.
Session input limit: 512 MB. This viewer does not open CSV files.
Individual plots are limited to 5 million samples across the selected signals/files.

The five starter groupings use actual supplied tags. AMI describes SmartARC inputs
including heat energy, arc stability, electrode position, voltage and current:
https://amiautomation.com/solutions/smartfurnace/smartarc/
Grouping and wording are this project's choices, not AMI-certified diagnostics.
